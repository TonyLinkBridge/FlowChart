原版的 detail（一坨 HTML 字符串）已被 note 取代：分成四块结构化数据 + 一段 markdown 自由说明。不再收 HTML —— 结构化的东西才导得出附注表、转得了 Mermaid、AI 也才改得动。
视图多吃的字段解锁什么
流程图 id · title · shape · edges 原样能跑
泳道 以上全部 + owner 按人分道
时间条 以上全部 + days 算关键路径
清单 以上全部 + done 跑进度条
兼容 老 flowmaker 文件直接能开，只是切到泳道时会提示「这几步还没填负责人」，点一下就能补。
自动保存 三层：本机立刻存、云端停手 2 秒存、版本 5 分钟合一版。打勾属于执行数据，立刻存但不产生新版本。
